## Atividade 3 — resultados disponíveis

Bateria de **08/11/2026**, com **12 respostas reais**, seis por versão. F1 médio: **A=0,748; B=0,701**. O sinal automático aprovou **5/6** em cada versão, com tau=0,5 fixado antes da execução.

O lote é **provisório**, porque a revisão humana prévia das referências está pendente. Os pareceres complementares estão identificados como **IA**; as 16 anotações humanas e as métricas de concordância humana ainda precisam ser concluídas. A atividade não está registrada como submetida.
