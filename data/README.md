# Dados
Fontes inteiramente sintéticas, criadas para AV2. Manifesto SHA-256 congelado. IDs são fontes locais, não URLs da web; validade significa ID existente/hash íntegro, não acesso à internet. URL inexistente é testada como referência fora do manifesto. Regenerar dados exige nova versão e não alterar resultados antigos.
